# Zen Crew

A modern community platform for people who want to **learn, build, connect, and grow together.**

## 🌐 About

Zen Crew is a community-focused website designed to introduce the community, connect users through Discord, and allow interested members to apply to join.

The website keeps the joining process simple and straightforward.

## 🚀 User Flow

Landing Page
     ↓
Join Discord
     ↓
Explore Community
     ↓
Application
     ↓
Submit Application
     ↓
Application Received
